# Сравнение Git и SVN

## 1. Почему в Git ветвление дешёвое, а в SVN дорогое?

В Git ветки создаются как лёгкие ссылки на коммиты, поэтому они создаются быстро.

## 2. Можно ли в SVN сделать коммит без интернета?

Нет. SVN является централизованной системой, и для коммита требуется доступ к центральному серверу. Git позволяет делать локальные коммиты без интернета.

## 3. Где SVN может использоваться сейчас?

SVN может использоваться в старых корпоративных проектах, где уже существует инфраструктура на его основе.
